## Part 2. Official precon "Counter Intelligence" (Edge of Eternities Commander, released 2025-08-01)

Face commander: **Inspirit, Flagship Vessel** (EOC #2). The official 100-card list has Inspirit as the commander and Kilo, Apogee Mind (EOC #3, foil) as one of the 99 cards. ## Notes and open points

- Scoring version: 2026.4196 for both (changelog). Deck pages do not display it.
- The Commander Salt leaderboard has a user deck titled "Counter Intelligence - CEDh" (commander Kilo, Apogee Mind, bracket 5.1, power 9.2, salt 215). It is not the official precon and was not scored here.
- Printings: Moxfield was checked for names and counts only. A read of the deck data was blocked by the browser tool, so the set and collector number of each row were not confirmed on Moxfield. The import used the file's set codes with "Override with preferred printings" OFF.
- Kilo-led precon: the official list has Kilo as a card. Scoring the same 100 cards with Kilo as commander needs a second Moxfield deck (not created; needs the owner's approval).
- Run inline in the main session on Haiku 5.5. No agents were launched.
